# Site de révision d'hébreu de Benjamin

https://hebreu-eight.vercel.app — quiz, flashcards, révision espacée, jeux, grammaire, conjugaison, statistiques.

- `donnees.js` et `passe-futur.html` : **les données de Benjamin** (vocabulaire, grammaire, conjugaison, cours Passé & futur).
- `index.html` : le site complet, **assemblé automatiquement** (action « Assembler le site », toutes les heures et à chaque changement des données)
  à partir des données ci-dessus et du code des exercices, qui vit dans le dépôt de Maayane
  (`Bensarfat/hebreu-avec-mayane`, `source/exercices/app.html`). Ne pas le modifier à la main.
